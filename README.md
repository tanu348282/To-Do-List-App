# 📝 To-Do List App (Python)

A simple command-line based To-Do List application built using Python.  
This app helps users manage daily tasks efficiently.

## 🚀 Features
- Add new tasks
- Update existing tasks
- Delete tasks
- View all tasks
- Menu-driven interface


## 🛠️ Technologies Used
- Python 3
